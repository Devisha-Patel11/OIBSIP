# OIBSIP – Web Development Internship (Level 2)

A collection of four front-end web development projects completed as part of the **Oasis Infobyte (OIBSIP) Web Development and Designing Internship – Level 2**.

This repository showcases practical implementation of HTML, CSS, and JavaScript through interactive and responsive web applications.

## 🚀 Projects

### 1. Calculator

A simple and interactive calculator that performs basic arithmetic operations through a clean user interface.

**Features**
- Addition, subtraction, multiplication, and division.
- Interactive calculator buttons.
- Clear and delete functionality.
- Responsive user interface.

**Technologies:** HTML, CSS, JavaScript

🔗 **[Live Demo]-https://devisha-patel11.github.io/OIBSIP/WebDev-L2-Calculator/**

### 2. Tribute Page – Sundar Pichai

A responsive tribute webpage dedicated to Sundar Pichai, CEO of Google and Alphabet. The page presents his biography, education, career journey, and achievements.

**Features**
- Biography and introduction.
- Education and career timeline.
- Major achievements and milestones.
- Responsive layout and navigation.
- Editorial-style visual design.

**Technologies:** HTML, CSS, JavaScript

🔗 **[Live Demo]-https://devisha-patel11.github.io/OIBSIP/WebDev-L2-TributePage/**

### 3. To-Do Web Application

A task management application that helps users organize daily activities, track progress, and manage priorities.

**Features**
- Add, edit, and delete tasks.
- Mark tasks as completed.
- Organize tasks by category and priority.
- Search and filter tasks.
- Set due dates and identify overdue tasks.
- Track task statistics and completion progress.
- Save tasks using browser Local Storage.

**Technologies:** HTML, CSS, JavaScript, Local Storage

🔗 **[Live Demo]-https://devisha-patel11.github.io/OIBSIP/WebDev-L2-TodoApp/**

### 4. Login Authentication System – AuthFlow

A front-end authentication interface demonstrating user registration, login, password validation, and session handling.

**Features**
- User registration and login.
- Form validation and error messages.
- Password visibility toggle.
- Password strength indicator.
- Remember me functionality.
- Forgot password demonstration.
- Dashboard after successful login.
- Session handling and logout.
- Browser-based user data storage.

**Technologies:** HTML, CSS, JavaScript, Web Crypto API, Local Storage, Session Storage

🔗 **[Live Demo]-https://devisha-patel11.github.io/OIBSIP/WebDev-L2-Authentication/**

> **Security Note:** AuthFlow is an educational front-end demonstration, not a production-ready authentication system. It stores data in browser storage and does not use a secure backend authentication service. Do not use real passwords or sensitive information.

## 💻 Run Projects Locally

You can run any project locally by following these steps:

1. Clone the repository:

```bash
git clone https://github.com/Devisha-Patel11/OIBSIP.git
```

2. Open the repository folder:

```bash
cd OIBSIP
```

3. Open the required project folder.

4. Run its `index.html` file in your browser.

You can also open the repository in Visual Studio Code and use the Live Server extension.
