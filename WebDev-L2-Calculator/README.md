# Calculator Web Application

A modern, responsive calculator web application built using HTML5, CSS3, and Vanilla JavaScript as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2, Task 1**.

## Project Overview

This project is a browser-based calculator designed to perform basic arithmetic operations through an interactive button interface. It features a dark neumorphic-inspired design, responsive layout, and custom JavaScript calculation logic without using `eval()`.

## Features

- Addition, subtraction, multiplication and division.
- Modulo operation.
- Decimal number calculations.
- Operator chaining with correct operator precedence.
- Clear All (AC) functionality.
- Delete (DEL) functionality.
- Division-by-zero error handling.
- Invalid expression handling.
- Responsive user interface.
- CSS Grid-based button layout.
- Event listeners for button interactions.
- Custom calculation engine without `eval()`.

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start performing calculations.

No additional packages or installations are required.
