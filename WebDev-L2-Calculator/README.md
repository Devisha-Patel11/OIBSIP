# Calculator Web Application

A modern, responsive calculator web application built using **HTML5, CSS3, and Vanilla JavaScript** as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2, Task 1**.

## 📌 Project Overview

This project is a browser-based calculator designed to perform basic arithmetic operations through an interactive button interface.

It features a dark, neumorphic-inspired design, a responsive layout, and a custom JavaScript calculation engine without using JavaScript's `eval()` function.

## ✨ Features

- Addition, subtraction, multiplication, and division.
- Modulo operation.
- Decimal number calculations.
- Operator chaining with correct operator precedence.
- Clear All (AC) functionality.
- Delete (DEL) functionality.
- Division-by-zero error handling.
- Invalid expression handling.
- Responsive user interface.
- CSS Grid-based calculator button layout.
- Event handling using JavaScript event listeners.
- Custom calculation engine without using `eval()`.

## 🚀 How to Run Locally

1. Clone or download the repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Make sure all project files are in the correct locations.
4. Open `index.html` in your web browser.
5. Start performing calculations!

**Note:** No additional packages or installations are required.
