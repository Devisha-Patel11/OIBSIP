# TaskFlow – To-Do Web Application

A modern, responsive, and user-friendly To-Do Web Application designed to help users organize daily activities, manage tasks, and improve productivity.

## 🌟 Project Overview

TaskFlow is a task management web application developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2, Task 3**.

The application allows users to create, organize, update, search, and track their daily tasks through a clean and responsive dashboard.

It uses browser Local Storage to save tasks, allowing users to retain their data even after refreshing or reopening the browser.

## ✨ Features

- **Add Tasks:** Create new tasks with a title, category, priority, and due date.
- **Edit Tasks:** Update existing task details.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Mark as Completed:** Mark tasks as completed or pending.
- **Task Filters:** Filter tasks by All, Pending, and Completed.
- **Search Tasks:** Quickly find tasks using keywords.
- **Category Management:** Organize tasks into Personal, Work, Study, and Other categories.
- **Priority Management:** Set Low, Medium, or High priority.
- **Due Date Tracking:** Assign deadlines and identify overdue tasks.
- **Progress Tracking:** View task statistics and completion percentage.
- **Local Storage:** Automatically save tasks in the browser.
- **Responsive Design:** Compatible with desktop, tablet, and mobile devices.

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Devisha-Patel11/OIBSIP.git
   ```

2. Navigate to the project directory:

   ```bash
   cd OIBSIP/WebDev-L2-TodoApp
   ```

3. Open `index.html` in your browser.

4. Alternatively, use the Live Server extension in Visual Studio Code.

**Note:** No backend or database installation is required. Tasks are stored locally in the browser.
