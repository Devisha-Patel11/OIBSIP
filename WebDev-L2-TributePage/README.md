# Sundar Pichai – Tribute Page

A responsive and visually appealing tribute webpage dedicated to **Sundar Pichai**, CEO of Google and Alphabet. This project highlights his life journey, educational background, career milestones, achievements, and contributions to the technology industry.

## 🔗 Project Links

- **Live Demo:** https://devisha-patel11.github.io/OIBSIP/WebDev-L2-TributePage/
- **GitHub Repository:**https://github.com/Devisha-Patel11/OIBSIP/tree/main/WebDev-L2-TributePage

## 🌟 Project Overview

This project is developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2, Task 2**.

The webpage presents Sundar Pichai's inspiring journey from Chennai to becoming one of the most influential leaders in the global technology industry.

## ✨ Features

- **Responsive Design:** Compatible with desktop, tablet, and mobile devices.
- **Hero Section:** Introduction with a prominent image and tagline.
- **Biography:** Information about his early life and background.
- **Education:** Highlights his academic journey.
- **Career Timeline:** Important milestones in his professional career.
- **Achievements:** Showcases his contributions to Google and the technology industry.
- **Inspirational Quote:** Features an inspirational message.
- **Navigation Bar:** Easy navigation between different sections.
- **Mobile Menu:** Responsive hamburger navigation for smaller screens.

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Devisha-Patel11/OIBSIP.git
   ```

2. Open the project folder:

   ```bash
   cd OIBSIP/WebDev-L2-TributePage
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
